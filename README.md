# TiltDrive Releases

Official update channel for the TiltDrive Android controller and Windows PC
receiver.

## Current versions

- Android app: **v0.17.8**
- Windows receiver: **v0.17.5**

The apps read `update.json` at most once every 24 hours and only open download
links hosted under this repository's GitHub Releases page. Updates are never
installed silently.

## Downloads

Open the repository's **Releases** page and select the latest published release.
